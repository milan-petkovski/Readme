# 🏛️ Tutz — Digitalno Središte za Strimere
Tutz predstavlja kompletan digitalni ekosistem dizajniran specijalno za potrebe savremenih strimera. Ovo nije samo sajt; to je centralna baza koja spaja fan portal, interaktivni live room i personalizovani shop u jednu fluidnu celinu visokih performansi.

Glavni fokus je na brzini, estetici i maksimizaciji angažovanja publike kroz premium korisničko iskustvo (UX).

---

## 🚀 Ključni Moduli Ekosistema

### 🎥 1. Interaktivni Live Room
Digitalna soba za fanove koja služi kao centralno mesto za praćenje svih društvenih mreža strimera u realnom vremenu.
*   **Tehnička Snaga**: Real-time integracije i dinamičko učitavanje sadržaja bez osvežavanja stranice (SPA).
*   **Funkcionalnosti**: Pregled najnovijih objava, live status, integrisani chat linkovi i interaktivni FAQ modul.

### 🛒 2. Tutz Shop
Premium e-commerce rešenje integrisano direktno u ekosistem, optimizovano za prodaju mercha i digitalnih proizvoda.
*   **Inženjerski Izazov**: Spajanje shopa sa glavnim portalom uz zadržavanje performansi i sigurnosti podataka.
*   **Funkcionalnosti**: Pregledna galerija proizvoda, optimizovan checkout proces i real-time inventar.

## ⚙️ Tehnološki Arsenal (Bleeding Edge)

| Tehnologija | Primena | Benefit |
| :--- | :--- | :--- |
| **Vite 8.0.13** | Build alat | Munjevito učitavanje i razvoj. |
| **React 19** | Core Framework | Najnovija arhitektura sa nula laga u UI tranzicijama. |
| **GSAP** | Animacije | Premium osećaj i fluidnost pokreta. |
| **Supabase** | Backend & Podaci | Sigurnost i real-time sinhronizacija baze. |
| **Tailwind CSS 4** | Dizajn sistem | Ultra-lagan CSS za vrhunske performanse. |

## 🛠️ Lokalno Podešavanje (Za Developere)

Ovaj projekat koristi monorepo strukturu:

1.  **Kloniraj repozitorijum**:
    ```bash
    git clone https://github.com/milan-petkovski/Tutz.git
    ```
2.  **Instaliraj zavisnosti**:
    ```bash
    npm install
    ```
3.  **Pokreni Website**:
    ```bash
    npm run dev:website
    ```
4.  **Pokreni Shop**:
    ```bash
    npm run dev:shop
    ```
