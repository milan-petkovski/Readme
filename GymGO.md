# ☕ Priča i Podrška
Zdravo! Ja sam Milan, 19-godišnji student i web developer iz Srbije. GymGo je nastao iz lične frustracije: većina fitnes aplikacija je pretrpana, spora i puna nepotrebnih distrakcija. Želeo sam da izgradim ekosistem koji deluje premium, radi trenutno i pruža značajne uvide bez suvišne "buke".

# 🚀 Ključne Funkcije

* 🏋️ **Pametno Praćenje Treninga**: Beleži serije, ponavljanja i težine uz inteligentan interfejs bez zastoja.
* 🥗 **Precizna Ishrana**: Sveobuhvatan budžet kalorija i istorija obroka sa funkcijom brzog dodavanja.
* 📊 **Pro Analitika**: Napredni trendovi volumena, prognoza progresa i vizuelni metrički podaci performansi.
* 🔐 **Cloud Sinhronizacija**: Sigurna, real-time sinhronizacija podataka na svim tvojim uređajima putem Supabase platforme.
* 📱 **Nativna Fluidnost**: Izgrađeno na React Native novoj arhitekturi za 120Hz glatke interakcije.
* 🎨 **Awwwards Dizajn**: Zadivljujući, moderan UI koji prati strogu premium estetiku.
* ⏳ **Fokus na Performanse**: Optimizovani build-ovi sa Vite 8 i Oxc za munjevito brzo web iskustvo.

# 🛠️ Instalacija i Podešavanje

1. **Kloniraj repozitorijum**:
   ```bash
   git clone https://github.com/milan-petkovski/GymGO.git
   ```

2. **Podešavanje Mobilne Aplikacije**:
   ```bash
   cd App
   npm install
   npx expo start
   ```

3. **Podešavanje Web Sajta**:
   ```bash
   cd Website
   npm install
   npm run dev
   ```
