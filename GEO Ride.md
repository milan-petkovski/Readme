# 🚀 Ključne Funkcije

* 🗺️ **Vožnja širom Sveta**: Istraži bilo koju lokaciju na Zemlji koristeći Mapbox satelitske snimke visoke rezolucije i realne podatke o terenu.
* 🏎️ **Napredna Fizika**: Realistično upravljanje automobilom, ubrzanje i drift mehanike pokretane prilagođenim Three.js engine-om.
* 🎥 **Filmska Kamera**: Dinamički sistem kamere koji prati vozilo uz glatku interpolaciju i filmski osećaj.
* 💥 **Sistem Kolizije**: Interaktivni engine za fiziku sa vizuelnim efektima udara i krhotina.
* 🛠️ **God Mode**: Posebne kontrole za developere za istraživanje bez kolizija i teleportaciju.
* ⚡ **Optimizovane Performanse**: Prilagođeno upravljanje memorijom radi sprečavanja curenja tokom dugih sesija vožnje.
* 📱 **Spreman za Mobilne**: Intuitivne touch kontrole za vožnju u pokretu.
* ⏳ **Pametno Učitavanje**: Optimizovana inicijalizacija sa praćenjem progresa za brz start.

<br>

# 🕹️ Kontrole

- **WASD / Strelice**: Vožnja i skretanje.
- **Space**: Ručna kočnica / Drift.
- **R**: Resetuj poziciju automobila.
- **SHIFT + R**: Resetuj automobil na početnu poziciju.

<br>

# 🛠️ Instalacija

1. Kloniraj repozitorijum:
   ```bash
   git clone https://github.com/milan-petkovski/GEO-Ride.git
   ```
2. Instaliraj zavisnosti:
   ```bash
   npm install
   ```
3. Kreiraj `.env` fajl sa tvojim Mapbox tokenom:
   ```env
   VITE_MAPBOX_TOKEN=tvoj_token_ovde
   ```
4. Pokreni razvojni server:
   ```bash
   npm run dev
   ```
